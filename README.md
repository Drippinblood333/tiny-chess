A chess engine in 4 KB of Python: negamax with alpha-beta pruning, quiescence search, a transposition table, killer-move ordering and piece-square evaluation, searching a fixed node budget per move so every trial replays deterministically. It plays the house gauntlet through the make.fun env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
